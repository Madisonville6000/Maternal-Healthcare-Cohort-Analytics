# Maternal Healthcare Indicator & Patient Cohort Dashboard
An interactive validation and visual reporting framework designed to evaluate maternal psychological distress scores and track symptom patterns across changing age groups.

## Strategic Objective
Maternal mental health risks frequently go unnoticed due to unorganized data capture channels, preventing healthcare administrative teams from prioritizing resources or deploying specialized screening toolkits to high-risk patient demographics proactively.

## Core Observations
Auditing and transforming a high-integrity clinical dataset of 1,502 respondents established an average structural baseline distress score of 5.03. Deep demographic parsing revealed that mental health distress is unevenly distributed, peaking significantly higher within the 35–40 age cohort due to clinical risk levels.

## Execution Blueprint
I cleaned and shaped the 12-variable dataset using Advanced Power Query to isolate missing string sequences and eliminate row duplicate blocks. This clean foundation was engineered into a Star Schema data model in Power BI, utilizing custom calculated measures to segment patient risk cohorts dynamically.

## Concrete Metrics
This solution replaces manual administrative logging backlogs with an automated diagnostic canvas. It isolates the high-risk 35–40 demographic with 100% accuracy, allowing deployment teams to route anxiety screenings and targeted community outreach toolkits directly where they are required most.

## Tech Stack Used
* Microsoft Power BI (DAX Scripting, Star Schema Relational Modeling)
* Advanced Power Query ETL Pipelines
* Microsoft Excel Data Validation
